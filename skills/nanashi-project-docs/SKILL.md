# Project Docs

## 一次資料の特定

1. プロジェクト内の指示と文書から、要件、設計、技術選定、規約の一次資料を特定する。
2. 一次資料が指定されている場合は、一般的な推測や汎用規約より優先する。
3. 見出し番号やセクション番号は変わり得るため、固定番号ではなく見出しと内容から参照先を特定する。
4. 同期物や生成物は直接編集せず、元データ側の変更方法を確認する。
5. 内容が実態と異なる場合は、対象文書、見出し、修正案をdiff形式で提示する。

## `docs/tmp/notion/`がある場合

- `docs/tmp/notion/`を一次資料として参照し、その時点の内容を正とする。
- `docs/tmp/notion/*.md`は生成物として扱い、直接編集しない。
- 最新化には、プロジェクトで定義された同期コマンドを使う。`npm run docs:sync`または`node scripts/tmp/sync-notion-docs.mjs`が定義されている場合は、それを使う。
- フォルダが存在しない場合も、同期コマンドで生成する。
- 内容変更はNotion側で行う。対象ページ、見出し、修正案を提示し、反映はユーザーに委ねる。
